01 / Question

What should an agent remember?

长期记忆并不是简单地把历史对话保存下来。研究重点是从 Session 和 Agent Trace 中判断哪些事实、事件、证据与行为值得长期保留，以及如何在需要时检索它们，同时避免低质量记忆持续污染后续上下文。

02 / Research

Comparing different memory paradigms.

当前研究持续比较不同长期记忆范式，尤其关注 Extract-first 与 Evidence-first 两条路径：前者强调先从交互中形成结构化记忆，后者强调保留更充分的原始证据，在检索与推理阶段再完成组织。

A / Extract-first

Structured memory first

先抽取可复用的事实或事件，再进入长期记忆存储与检索。

B / Evidence-first

Evidence before summary

优先保留可追溯证据，减少过早摘要带来的信息损失。

C / Retrieval

Hybrid access

探索结构化记忆与原始证据之间的混合检索和上下文组合。

D / Consolidation

Memory lifecycle

研究记忆更新、巩固、冲突处理与长期质量控制。

Research direction

目标不是让 Agent “记得更多”，而是让记忆来源可追溯、检索有意义、对任务真正有帮助，并能够通过 Benchmark 持续验证。
