01 / Overview

Memory as a system, not a storage feature.

研究从 Session 和 Agent Trace 中自动抽取长期记忆，并关注混合检索、记忆巩固与 Benchmark 评测闭环。当前重点比较 Extract-first 与 Evidence-first 两类路径，并继续探索新的记忆组织方式。
