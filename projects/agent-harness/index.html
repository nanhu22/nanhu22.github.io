01 / Overview

The control layer around an agent.

Agent Harness 研究关注模型之外的运行系统：任务如何被编排、工具如何被约束、上下文如何被组织、Trace 如何被记录，以及整个 Agent 在长链路执行中如何保持可观测和可控。

A / Runtime

Execution model

Agent loop、任务状态、工具执行与运行边界。

B / Context

Control & context

上下文装配、策略约束、重试与执行控制之间的关系。

C / Observability

Trace & evaluation

如何记录 Agent 行为，并让错误、成本与性能可以被分析。

D / Output

Harness patterns

系统模式、原型、案例、实验与后续可复用的基础设施。

Runtime diagrams, traces and engineering evidence will be added with the full research material.
